# 🐾 ZOOMIES! どうぶつ自転車バトル

かわいいどうぶつたちと競う、Zwift 風の 3D サイクリングレースゲームです。
ブラウザだけで動き（ビルド不要）、Bluetooth のパワーメーターやスマートトレーナーをつなぐと実際のペダリングで走れます。

▶ 遊ぶ：`https://ogakuzu.github.io/zoomies/`

## 特徴

- **迫力の走行**：速度で広がる視野角、カメラの揺れ、マンガ風の集中線、風切り音。下りは 70km/h 超え
- **かわいいキャラクター**：ねこ・しばいぬ・うさぎ・くま・パンダ・ペンギン・きつね・ハムスター・オオカミ
- **スリリングな展開**：逃げ・アタック・山岳アタック・終盤の仕掛け・ゴールスプリント。沿道の観客と実況つき
- **熱い対戦**：ライバル「ガロウ」とのバトル、山岳賞・スプリント賞、アイテム、表彰台、1台で遊べる 2人対戦（画面分割）
- **パワーメーター接続**：Web Bluetooth で下記の機器に対応

| 機器 | Bluetooth サービス | 用途 |
| --- | --- | --- |
| パワーメーター | Cycling Power (0x1818) | パワー・ケイデンス |
| スマートトレーナー | Fitness Machine / FTMS (0x1826) | パワー・ケイデンス・**勾配の再現（SIM モード）** |
| 心拍計 | Heart Rate (0x180D) | 心拍数 |
| ケイデンスセンサー | Cycling Speed and Cadence (0x1816) | ケイデンス |

接続できるブラウザ：PC / Android の Chrome・Edge（iPhone は「Bluefy」アプリ）。HTTPS でのアクセスが必要です（GitHub Pages は OK）。

## あそびかた

- **パワーメーターあり**：実際のワット数で走ります。スマートトレーナーならコースの坂に合わせて負荷が変わります（トレーナー難易度で調整）
- **キーボード（1人）**：押さなければ前のライダーに自動でついていきます
  - `↑` / `W` アタック、`↓` / `S` 休む、`Space` もがく（全力スプリント・連打でさらにUP）
  - `E` アイテム、`←` `→` 横移動、`C` カメラ切替、`M` ミュート、`P` / `Esc` ポーズ
- **2人対戦（1台のPC）**：P1 `W` `S` `D` `A`、P2 `↑` `↓` `→` `←`（アタック・休む・もがく・アイテム）
- **スマホ・タブレット**：画面のボタンで操作

スタミナ（W′）は FTP を超えるパワーで減り、休むと回復します。ゼロになると 💫 ヘロヘロになるので、仕掛けるタイミングが勝負です。

## しくみ（ファイル構成）

| ファイル | 内容 |
| --- | --- |
| `js/main.js` | 起動・状態遷移・ゲームループ・描画 |
| `js/course.js` | 周回コース（極座標のループ＋勾配プロファイル） |
| `js/world.js` | 空・地形・道路・木・観客・ゲート・テーマ別の景観 |
| `js/rider-model.js` | どうぶつライダーと自転車（IK ペダリング・表情） |
| `js/physics.js` | パワー→速度、ドラフティング、W′ バランス |
| `js/ai.js` / `js/race.js` | AI ライダー、レース展開ディレクター、順位・区間・アイテム |
| `js/ble.js` | Web Bluetooth（GATT パーサ・FTMS 制御） |
| `js/controls.js` | キーボード・タッチのバーチャルパワー |
| `js/camera.js` / `js/fx.js` | カメラワーク、集中線・風・紙吹雪 |
| `js/hud.js` / `js/commentary.js` / `js/ui.js` | HUD、実況、メニュー |
| `js/audio.js` | 効果音・チップチューン BGM・実況ボイス（Web Speech） |

URL パラメータ：`?quality=high|mid|low`（画質）、`?touch=1`（タッチボタン表示）、`?mockble=1`（デモ用の疑似パワーメーター）
