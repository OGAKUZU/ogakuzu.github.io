# 🫧 シミぬきラッシュ！ しあわせクリーニング

お店の SNS で公開するための、クリーニング豆知識が身につくアクションゲームです。
ブラウザだけで動きます（ビルド・インストール不要、スマホ縦画面向け）。

▶ 遊ぶ：`https://ogakuzu.github.io/cleaning/`

## あそびかた

- ハンガーレールでお洋服が流れてくる → 下の道具をえらんでシミをタップ
- シミの種類に合った道具でないと「にじんで」広がる（正しい落とし方をその場で解説）
- ピカピカにするとタイムが少し回復、シミが残ったまま流れるとタイムが減る
- しあわせゲージ満タンで **FEVER!**（どの道具でも一発・得点2倍）

| 道具 | 種類 | シミ |
| --- | --- | --- |
| 💧 水でたたく | 水溶性 | コーヒー・赤ワイン・ジュース・汗じみ |
| 🧪 溶剤 | 油性 | 口紅・ボールペン・揚げ物の油 |
| 🧊 冷水＋酵素 | タンパク質 | 卵・牛乳（お湯は固まるのでNG） |
| 🪥 ブラシ | 乾いた汚れ | 泥はね・花粉（濡らすと広がる） |

落としたシミは「シミ図鑑」にたまり、豆知識をいつでも読み返せます。
結果画面には称号・シェアボタン・お店からのメッセージが出ます。

## お店の情報を変えるには

`index.html` の先頭付近にある `SHOP` を書きかえてください。

```js
const SHOP = {
  name: 'まちのクリーニング屋さん',   // お店の名前
  message: 'シミは時間との勝負！…',   // 結果画面のメッセージ
  url: '',                            // お店のページ（Instagram など）。空ならリンクなし
  hashtag: 'シミぬきラッシュ',         // シェア時のハッシュタグ
};
```

`og.png` は SNS でリンクを貼ったときに表示されるプレビュー画像です。
