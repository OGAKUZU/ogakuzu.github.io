## 作業ファイルが消えていたら

コンテナが再起動すると scratchpad は消えます。そのときは
このフォルダの `board.html` をコピーして作り直してください。

```
cp automation/board/board.html <scratchpadのパス>/board.html
```

再公開は同じ file_path で Artifact ツールを呼ぶだけです（URLは変わりません）。

## 構成（この順番を守る）

| # | ブロック | 中身 |
|---|---|---|
| 1 | 判定バンド | 動く日 ／ ようす見の日 ／ 休む日 |
| 2 | 今日やること | 4ステップ。番号付き |
| 3 | 買うならこれ | 見込み% ＋ メーター（40%の線）＋ 注文の作り方 |
| 4 | 今日は買わないもの | 箇条書き |
| 5 | 相場 | 3セル。取れない数字は「取得不可」 |
| 6 | イベント | 逆算カレンダー |
| 7 | たたんだ詳細 | 用語 ／ なぜこの% ／ 実績 ／ 報告 |

## 書き方のルール

- 中学生にも分かる言葉。1文を短く
- **文字数を増やさない**（増えると読まれない）。専門用語は「用語」の折りたたみへ
- 取れなかった数字は推測せず「取得不可」
- 銘柄コードは開示原文と照合。確認できなければ「※未確認」
- 上場市場を必ず書く（札証・名証・福証の単独上場は原則載せない）
