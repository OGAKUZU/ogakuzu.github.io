# 日本株モーニングリサーチ 自動化設定

毎朝5時（日本時間）に自動でWeb調査を行い、銘柄購入の判断に役立つ公開情報を
まとめたレポートを配信する仕組みの設定記録です。

## 仕組み

Claude Code の Routine（定期実行トリガー）として動作します。GitHub Actions
ではなく Claude 側のスケジューラで動くため、このリポジトリのコードは実行に
関与しません（このファイルは設定内容の控えです）。

- **朝のトリガーID**: `trig_01GmdpacZ35wwucssCNwJ64i`（v3）
  （旧v1/v2はカテゴリ追加のたびに削除・再作成済み）
- **検証トリガーID**: `trig_01DLBQHiphRnW6xt7youHtNK`
  （平日 UTC 9:00 = 日本時間 18:00。朝イチ候補を当日の値動きで答え合わせし、
  Excel台帳「朝イチ検証台帳 YYYY-MM-DD.xlsx」をドライブに保存。
  プロンプト全文は automation/verification-prompt.md）
- **スケジュール**: 毎日 UTC 20:00（日本時間 翌朝5:00頃）
- **実行方式**: 毎回新しいセッションを起動して調査を実行
- **通知**: 完了時にスマホへのプッシュ通知＋メール（ytatamura@gmail.com）
- **保存先**: Google ドライブの「日本株モーニングリサーチ」フォルダに
  Google ドキュメント「日本株モーニングリサーチ YYYY-MM-DD」として保存。
  併せて Markdown ファイルもセッションに添付送信。

## 第0部: 朝イチ候補リスト（レポート最上段）

当日の寄り付きでギャップアップ/物色が予想される銘柄を、鮮度・確度順の表で
毎朝リストアップします。情報源は (a) 前営業日大引け後のTDnet開示（上方修正・
自社株買い・増配・大型受注・TOB等）、(b) PTSナイトタイムセッションの
騰落ランキング、(c) 前夜の米国市場（ダウ・ナスダック・SOX・日経先物）、
(d) 当日朝の観測報道。各銘柄に「材料 / PTS織り込み度 / 想定シナリオ」を付記し、
PTS+15%超の銘柄は高値掴み警告、材料未確認の急騰は見送り推奨として区別します。
短期候補には損切りライン（買値-3〜5%または当日安値割れ）の設定を毎回明記。

## 技術メモ: 実行方式（v4で変更）

当初は「毎回新しいセッションを起動」する方式だったが、新セッションには
GoogleドライブやPushNotificationなどのコネクタ（MCP接続）が引き継がれず、
調査はしても保存・通知ができない障害が発生（7/12〜7/14朝の3回分が未達）。
v4からは「メインの会話セッションに戻って実行する」方式（persistent_session
バインド）に変更。この方式なら会話に接続済みのドライブ・通知がそのまま使える。
別アカウントで再現する場合も、Routineは「この会話で実行」を指定すること。

## 技術メモ: EDINET API について

EDINET API (api.edinet-fsa.go.jp) は海外IPからのアクセスを遮断しているため、
この実行環境（米国経由）からはAPIキーの有無にかかわらず403となり直接利用
できません。大量保有報告書などEDINET由来の情報は、Web検索経由で国内ミラー
（株探ニュース、M&A Online 大量保有速報、会社四季報オンライン等）から取得
する方式にしています。APIキーはリポジトリには保存しません。

## 第1部: 毎朝調査する8カテゴリ

1. **EDINET 大量保有報告書・TDnet 適時開示** — 前営業日の新規5%取得・
   買い増し（アクティビスト最優先）、上方修正、自社株買い、増配
2. **イベント逆算カレンダー** — 今後2週間の決算発表、日銀会合、FOMC、
   政府イベント、SQ日と「何日前から物色が始まるか」の解説
3. **政府審議会・パブコメ・入札・補助金** — 経産省等の新着資料、
   NEDO等の補助金採択者リスト、官公需の大型落札情報のうち
   予算措置・産業支援策（AI・半導体・防衛・GX・宇宙）に絡むもの
4. **月次データ・進捗率** — 月次売上の急伸/急落、上方修正が近い高進捗銘柄
5. **業界統計・海外の先行指標** — 工作機械受注、SEMI、
   マルチ・スズキ月次、SIAM に加え、TSMC月次売上（毎月10日頃）、
   韓国1〜20日輸出速報（毎月21日頃）、米大手顧客決算からの読み替え
6. **需給・機関投資家の足跡** — JPX空売り残高報告（0.5%以上は機関名
   入りで公表）、投資部門別売買状況（海外投資家の買い越し/売り越し、
   毎週木曜）、逆日歩・信用倍率の急変
7. **決算説明会の書き起こし** — ログミーファイナンス等の新着で
   来期示唆を含む質疑応答
8. **求人・特許・設備投資シグナル** — 増産・新工場・新事業の先行指標。
   環境アセスメント公告・大型建築計画（着工前に新設が分かる）も対象

## レポートの約束事

- 中学生にも分かる言葉で書き、専門用語には毎回一言の説明を付ける
- 冒頭に「今朝の3行サマリー」
- 各項目は「事実（出典付き）→ 解説 → 関連銘柄（コード付き）→ アクション」
- アクションは原則「ウォッチリスト追加」まで。エントリーは日足チャートで
  MA75（75日移動平均線）を自分の目で確認してから
- 未公表情報は扱わない（公開情報のみ）。末尾に免責事項を明記

## 保険: GitHub Actions版バックアップ

Claude の課金が切れて Routine が止まった場合に備えたバックアップを
リポジトリに同梱しています（普段は休眠していて、料金はかかりません）。

- **仕組み**: `.github/workflows/daily-stock-research.yml` が毎日
  UTC 20:00（日本時間 朝5時）に `automation/run_research.py` を実行。
  Claude API のWeb検索ツールで同じ調査を行い、レポートを
  `reports/YYYY-MM-DD.md` としてコミットする（スマホのGitHubアプリや
  リポジトリページから読める）
- **休眠条件**: リポジトリシークレット `ANTHROPIC_API_KEY` が未設定の間は
  何もせずスキップされる

### 有効化する手順（3ステップ）

1. https://console.anthropic.com でAPIキーを発行（従量課金。クレジット
   を事前チャージする方式なので使いすぎの心配が少ない）
2. GitHubリポジトリの Settings → Secrets and variables → Actions →
   New repository secret で `ANTHROPIC_API_KEY` を登録
3. このブランチを main にマージ（scheduleトリガーはデフォルトブランチ
   でのみ動作するため）。初回は Actions タブ → daily-stock-research →
   Run workflow で手動実行して動作確認する

### 費用と注意

- モデルは既定で claude-opus-4-8（環境変数 `RESEARCH_MODEL` で変更可）。
  1回の実行はWeb検索約20回＋レポート生成で、目安として数十円〜百数十円
  程度/日（為替・調査量により変動。初回実行後にconsoleの使用量で確認を）
- このリポジトリが公開（public）の場合、`reports/` のレポートも公開される。
  非公開にしたい場合はリポジトリをprivateにするか、別リポジトリに分離する

## 変更・停止したいとき

Claude Code のセッションで以下のように依頼してください。

- 停止: 「トリガー `trig_01GmdpacZ35wwucssCNwJ64i` を無効化して」
- 時刻変更: 「モーニングリサーチの実行時刻を朝6時（JST）に変えて」
  （cron は UTC 基準。JST 6:00 = `0 21 * * *`）
- 調査内容の変更: トリガーを削除して新しいプロンプトで再作成
