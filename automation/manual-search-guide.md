# 手動リサーチ手順書（AIが使えない朝のための「自分でやる版」）

トークン（AI利用量）が尽きた・課金が切れた等でAIの自動リサーチが止まっても、
あなた自身で同じことを **スマホで10〜15分** でできるようにした手順書です。
毎朝これをなぞれば、AI版の8割は再現できます。ブックマーク推奨。

専門用語には毎回カッコで一言説明を付けています。

---

## 使い方の全体像

- **やる時間**: 朝 7:00〜8:50（東証の寄り付き＝取引開始は9:00）。前夜でも可。
- **順番が命**: 下の①→⑥を上から順に。上ほど「鮮度が高く・値動きに直結」します。
- **鉄則（毎回思い出す）**:
  - PTS（夜間取引）で+15%超は原則見送り
  - 寄り成り（＝始値でなんでもいいから買う注文）は使わない
  - 買う前に損切りライン（買値-3〜5% または 当日安値割れ）を必ず決める
  - 「材料の中身」で選ぶ。「PTSで上がってるから」で飛びつかない
    （※ 2026-07-14の検証で、PTS急騰は寄りで消えると実証済み）

## ① 前日引け後のTDnet適時開示（最重要・鮮度最高）

**何を見る**: 昨日15時以降に企業が出した「上方修正・自社株買い・増配・大型受注・
TOB（買収）・業務提携」。これが翌朝の値動きを一番作ります。

- **サイト**: TDnet 適時開示情報閲覧サービス → `https://www.release.tdnet.info/inbs/I_main_00.html`
- **見方**: 当日/前営業日を選び、「業績予想の修正」「配当予想の修正」「自己株式の取得」
  「特別利益」などの見出しを拾う。上方修正の「率」が大きいものほど注目。
- **かんたん版（スマホ向き）**: 株探の「決算速報・サプライズ」
  → `https://kabutan.jp/news/marketnews/?category=9`
  「前期比◯％増」「上方修正」を上から確認。

## ② PTS（夜間取引）の値動きランキング

**何を見る**: 昨夜〜今朝、証券取引所の時間外で買われた/売られた銘柄。
材料への「反応の速報」。ただし**寄りで消えやすい**ので過信しない。

- **サイト**: 株探「PTS株価ランキング」→ `https://kabutan.jp/warning/?mode=2_9`
  （または「PTS ランキング 株探」で検索）
- **見方**: 上昇率上位を見て、①のTDnet開示と結びつくものは「本物寄り」。
  材料が見当たらない急騰（特に低位株＝株価が数十円の銘柄）は**見送り**。
- **判定の目安**:
  - PTS +3〜10% ＋ 業績など明確な材料 → ウォッチ候補
  - PTS +15%超 / 材料不明 → 見送り（高値掴みの罠）

## ③ 前夜の米国市場と日経先物（地合い＝その日の雰囲気）

**何を見る**: 相場全体が追い風か向かい風か。個別銘柄の勝率が変わります。

- **サイト**: みんかぶ・Yahoo!ファイナンスの「米国市場」欄、または「NYダウ ナスダック SOX 前日」で検索
- **見るもの**: ダウ / ナスダック / **SOX（半導体株指数）** / 日経225先物 / ドル円
- **読み方**:
  - ナスダック・SOXが上げ → ハイテク・半導体が買われやすい日
  - 全面安 → 無理せず様子見。逆指値を浅めに
  - **時間外（今朝の先物）も見る**。夜と朝で逆のことがある

## ④ イベント逆算カレンダー（今日〜2週間の予定）

**何を見る**: 決算発表・日銀会合・FOMC（米金融政策会合）・SQ（先物清算日）。
「◯日前から物色が始まる」ため、事前に構えられます。

- **サイト**: 株探「決算発表予定」→ `https://kabutan.jp/warning/?mode=3_1`
  Yahoo!ファイナンス「経済指標カレンダー」
- **使い方**: 気になる銘柄の決算日を手帳に。決算3〜5営業日前は期待買いが入りやすい。

## ⑤ 大量保有報告書（EDINET・機関/アクティビストの動き）

**何を見る**: 誰か（ファンド等）がある会社の株を5%以上買った/買い増した届出。
アクティビスト（物言う株主）が入ると株価が動きやすい。

- **サイト（PCで直接使える）**: EDINET → `https://disclosure2.edinet-fsa.go.jp/`
  「書類検索」→ 提出書類種別で「大量保有報告書」
  ※ **日本のネット回線からなら公式が普通に使えます**（海外経由だと遮断されます）
- **かんたん版**: 「大量保有速報 M&A Online」または「株探 大量保有」で検索

## ⑥ 月次・業界統計・海外の先行指標（中期のタネ）

**何を見る**: 毎月出るデータで、決算より早く業績の good/bad を察知。

- 月次売上（各社IRページ／株探の適時開示）: 前年同月比が急伸→上方修正が近いことも
- **TSMC月次売上**（毎月10日頃）→ 半導体の需給を先読み
- **韓国 1〜20日 輸出速報**（毎月21日頃）→ 世界景気の体温計
- 工作機械受注・SEMI（半導体製造装置）統計 など

## 朝の10分・実行チェックリスト（これだけでもOK）

1. [ ] 株探「決算サプライズ」で前日引け後の上方修正・自社株買いを3件拾う（①）
2. [ ] 株探「PTSランキング」上位を見て、①と結びつく銘柄に◯、材料不明の急騰に×（②）
3. [ ] ナスダック・SOX・日経先物の方向を確認（追い風/向かい風）（③）
4. [ ] ◯を付けた候補について「寄り成りしない・損切りライン決め・15分様子見」を自分に言い聞かせる
5. [ ] 買うなら、始値で飛びつかず、寄り後5〜15分の値固まりを見てから指値

## 買った後の「答え合わせ」も手動で

夕方、候補が実際どう動いたかを1行メモするだけで上達します。
- 始値 / 高値 / 安値 / 終値 を株探の個別銘柄ページで確認
- 「寄り天（寄り付きが天井）だったか？」「逆指値-3%は発動したか？」を記録
- これを続けると、AI版の検証台帳と同じ学びが手元に貯まります
