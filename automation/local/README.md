# ローカル運用ツール（あなたのPCで動かす道具）

Claudeが作り、**あなたのPCのローカルLLM（LM Studio）が実行する**ための道具です。
クラウド課金なし・無制限・場中いつでも使えます。

---

## セットアップ（初回だけ・5分）

### 1. LM Studioでサーバーを起動
1. LM Studioを開く
2. 左のアイコンから **Developer（`</>`）** タブを選ぶ
3. **Start Server** を押す（既定は `http://localhost:1234`）
4. モデル（Gemma 4 E4B など）が読み込まれていることを確認

> 💡 **速度改善**: 設定で **Reasoning/Thinking を OFF** にすると3〜5倍速くなります。要約作業に思考モードは不要です。

### 2. Pythonの準備
コマンドプロンプト（スタートメニューで「cmd」と検索）で：
```
pip install requests
```
※Pythonが無い場合は https://www.python.org/downloads/ からインストール（**「Add python.exe to PATH」に必ずチェック**）

### 3. kabu.py を保存
このフォルダの `kabu.py` を、分かりやすい場所（例：`C:\kabu\kabu.py`）に置く。

---

## 使い方

コマンドプロンプトで、置いた場所へ移動してから実行します。
```
cd C:\kabu
```


### まず接続確認（うまくいかない時はこれ）
```
python kabu.py --check
```
- `✅ 接続OK。利用できるモデル: ...` → 準備完了
- `⚠️ モデルが読み込まれていません` → LM Studioで **「+ Load Model」(Ctrl+L)**
- `❌ サーバーに届きません` → Developer タブで **Start Server**

### 開示・決算を解読する（いちばん使う）
```
python kabu.py
```
→ 本文を貼り付け → **Ctrl+Z を押して Enter** → 30秒ほどで解説が出ます

### 決算の「予想比」をチェックする
```
python kabu.py -m b
```
先週のディスコ（4割増益でも予想割れで急落）・信越化学（増配でも計画が予想割れで-6%）の
失敗を繰り返さないためのモードです。

### 材料の質を25点満点で採点する
```
python kabu.py -m c
```

### 用語をその場で調べる
```
python kabu.py -m d -t 逆日歩
```

### ファイルから読み込む
```
python kabu.py -f news.txt
```

## 🔑 EDINET連携（あなたのPCだけの特権）

**EDINET API（金融庁の開示システム）は海外IPを遮断しています。**
クラウドのClaudeからは403で使えませんが、**日本にあるあなたのPCからは使えます。**

### 準備
1. https://api.edinet-fsa.go.jp/ でAPIキーを取得（無料）
2. コマンドプロンプトで環境変数に設定（**そのウィンドウを閉じるまで有効**）：
```
set EDINET_API_KEY=あなたのキー
```
※毎回設定するのが面倒なら、Windowsの「システム環境変数の編集」で恒久設定できます

### 使う
```
python kabu.py --edinet                    # 今日の大量保有報告書を一覧表示
python kabu.py --edinet --analyze          # ＋ローカルLLMが解説
python kabu.py --edinet --date 2026-07-30  # 日付を指定
```

**なぜ重要か**: 大量保有報告書は「誰が・どの銘柄を・何%買ったか」の一次情報です。
アクティビスト（＝物言う株主）の買い増しは、ニュースになる前に分かります。
**朝のレポートより速い情報が、あなたのPCから直接取れます。**

## 実戦での動線

```
SBIアプリのアラートが鳴る（+5%上昇 など）
  ↓
株探やSBIで開示・記事を開く → 本文をコピー
  ↓
python kabu.py  → 貼り付け → Ctrl+Z → Enter
  ↓
30秒で「何がすごいか・注意点・予想比は分かるか」を把握
  ↓
朝レポートで決めた鉄則（損切りライン・見送り基準）で判断
```

## 困ったとき

| 症状 | 対処 |
|---|---|
| つながらない | LM StudioでStart Serverを押したか確認 |
| 遅い（1分以上） | Reasoning/ThinkingをOFF、Context Lengthを4096に |
| 落ちる | モデルを小さく（8B→4B）、他アプリを閉じる |
| EDINETが403 | APIキーを確認。VPNを使っていればOFFに（海外IP判定される） |
| 日本語が変 | Gemma系かQwen系のモデルに変更 |

---

## 注意

- ローカルLLMは**貼り付けた文章の中身しか知りません**。「今日の株価は？」と聞かないこと（もっともらしい嘘をつきます）
- 出力の数字は**必ず原文で確認**してください
- 本ツールの出力は公開情報の整理であり、投資助言ではありません
