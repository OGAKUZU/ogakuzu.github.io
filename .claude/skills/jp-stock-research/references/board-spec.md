# 朝イチ判定ボードの仕様

配信物はこのボード1枚だけ。**Markdownレポートとxlsx添付は2026-08-25に廃止した。**

## 構成（この順番を守る）

| # | ブロック | 中身 |
|---|---|---|
| 1 | **判定バンド** | 「動く日」／「ようす見の日」／「休む日」＋ 2行の理由 |
| 2 | **今日やること** | 番号付き4ステップ。1ステップ1行＋補足1行まで |
| 3 | **買うならこれ** | 銘柄カード。原則1〜2件まで |
| 4 | **今日は買わないもの** | 箇条書き。理由は太字1語＋1文 |
| 5 | **相場** | 3セル。取れない数字は「取得不可」 |
| 6 | **イベント** | 逆算カレンダー |
| 7 | **たたんだ詳細** | 用語 ／ なぜこの% ／ 実績 ／ 報告 |

**1画面目に収めるのは 1 と 2 だけ。** それ以外はスクロールの下。

## 銘柄カードに必ず入れるもの

- 銘柄名 ／ **コード** ／ **市場**（東証プライム・グロース等）
- うまくいく見込み% ＋ メーター（**40%の位置に線を引く**）
- 材料を2行で（なぜ良いのかまで）
- **注文の作り方**（下記6項目）

### 注文の作り方（6項目・省略しない）

| 項目 | 書き方 |
|---|---|
| 買う時間 | 9:15すぎ（朝いちばんは買わない） |
| 買い方 | 値段を決めて注文（成行はダメ） |
| 金額 | 判定に応じて「いつもの半分」等 |
| **やめる値段** | 買った値段の -4%（または当日安値割れ） |
| 利益の目安 | +6% か、その日の終わりで手じまい |
| 買わない条件 | 朝の最初の値段が前日より +8% 以上なら見送り |

**株価そのもの（〇〇円で買う）は書かない。** 現在値を取得できないので、書けば嘘になる。**「朝の値段を見てからこう決める」というルールの形**にする。

## 書き方のルール

- **中学生に分かる言葉。1文を短く。**
- **文字数を増やさない。増えると読まれない。**
- 専門用語は本文で使わず、**「用語」の折りたたみ**に逃がす
  （成行・指値・寄り付き・損切り・初配・自社株買い など）
- 「期待度%」は本文では **「うまくいく見込み」** と書く
- 取れなかった数字は「取得不可」＋なぜ取れなかったか一言
- 自分のミスを見つけたら、**隠さずボードに書く**（「報告」の折りたたみ）

## 見た目

- 上げが**赤**、下げが**青**（日本の板と同じ。証券アプリと目が混乱しないため）
- ライト／ダークの両対応。色は必ずトークン（CSS変数）経由で指定する
- スマホ幅が基準。表は `overflow-x: auto` の中に入れる

## 毎回書く鉄則

寄り成り買いは使わない ／ 買う前に損切りラインを決める ／ PTS+15%超は見送り ／ 上場市場と出来高を確認する。
