# 🎞️ コマドリ！ かんたんストップモーション

写真を撮って並べるだけで、ストップモーション動画が作れるWebアプリです。
ブラウザだけで動きます（ビルド・インストール不要、スマホ向け）。

▶ 使う：`https://ogakuzu.github.io/stopmotion/`

## 2つの作り方

| モード | 向いている使い方 | しくみ |
| --- | --- | --- |
| ✨ かんたん | 写真が2〜5枚しかない | 写真と写真のあいだを自動でなめらかにつなぎ（クロスフェード）、ゆっくりズームで動きを足す |
| 📸 そのまま | たくさん撮ってパラパラ動かしたい | 1枚＝1コマで再生。速さは1秒に2〜24コマ |

## 使い方（3ステップ）

1. **撮る・選ぶ** — 「カメラで撮る」で撮影（前のコマが薄く重なる「👻 重ね」表示つき）、または「写真を選ぶ」でまとめて追加
2. **並べる** — コマをタップして ◀ 前へ / 後へ ▶ / 複製 / 削除
3. **動画にする** — プレビューを見ながら速さ・効果を調整して「🎬 動画にする」→ 保存 or 共有

- 効果：なめらかにつなぐ / ゆっくりズーム（かんたん）、手作りゆれ（そのまま）、行って戻る（共通）
- くり返し 1〜5回、形は 自動 / 横長 / 縦長 / 正方形
- 書き出しは MP4（対応ブラウザ）または WebM。長辺1280px
- 写真と設定は端末内（IndexedDB）に自動保存され、次に開くと続きから作れます。サーバーには送信しません
